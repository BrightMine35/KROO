# K-ROO Live

Static site for **K-ROO Student Radio** at the University of Missouri–Kansas City.

## 🛠 Deployment

Domain from porkbun
👉 https://k-roo.digital

When you push to `main`, Porkbun publishes changes automatically.

## 📡 Streaming

Currently streams from a temporary demo URL: https://icecast.radiofrance.fr/fiprock-midfi.mp3

Replace that link in `index.html` once your official Icecast stream is live.

## 🧱 Local testing
python3 -m http.server 8080

Then open http://localhost:8080
